# flask-shop-admin
Мини-админка для управления товарами в интернет-магазине. Можно добавлять, редактировать и удалять товары. Есть загрузка картинок, так что товары не просто текстовые, а с картинками. Данные хранятся в SQLite.

Что умеет:
Просмотр всех товаров в таблице
Добавление нового товара (название, категория, цена, картинка)
Редактирование товара (всё то же самое, но с уже заполненными полями)
Удаление товара
Загрузка изображений на сервер

Стек:
Python 3.7+
Flask
Flask-SQLAlchemy
SQLite
HTML + CSS (без шаблонизаторов, чистая вёрстка)
